# Binary recap

<!-- FAKE DATA: invented teaching notes for screenshots -->

- A bit is a single 0 or 1; a nibble is 4 bits; a byte is 8 bits.
- Place values in an 8-bit number: 128, 64, 32, 16, 8, 4, 2, 1.
- To convert denary to binary, subtract the largest place value that fits.
- Overflow happens when a result needs more bits than are available.

## Try these

1. Convert 0110 1011 to denary.
2. Convert 201 to 8-bit binary.
3. Add 1011 0110 and 0101 1100. Does it overflow?
