✓ Stored, on this Mac only

Your settings, an index of your resources folder, run counts. Every path listed on the Privacy page.

✕ Never stored

Names, candidate numbers, classes, per-pupil grades. Marks files lose identifier columns on load.

⌕ Check it yourself

One config folder of readable files; the only network use is the update check. A head of department can verify it in five minutes.

What comes out
WorksheetSeeded binary, logic, file-size and compression questions, key on its own sheet.
ParsonsA program cut into numbered blocks, with distractors and an answer grid.
TraceBlank and completed trace tables from a real run.
MarksGrades and the questions to reteach from a mock. Aggregates only.
QuizOne Markdown bank → Kahoot, Forms text or a printed do-now.
ClassroomOpen a resource for a lesson on a copy; the original never changes.
