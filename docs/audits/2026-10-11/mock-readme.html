Staffroom

Small tools for secondary computing teachers, on your own Mac. Make a seeded binary worksheet with its key, a Parsons problem or a trace table from a program, a do-now from a question bank, and see which questions a class found hardest in a mock. Everything prints in one plain house style. No pupil names, ever.

Install (macOS)

Two lines in Terminal. The first installs uv, which fetches everything else; skip it if you have uv.

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install --python 3.12 git+https://github.com/ColePoppleton/Staffroom@main

Then type staffroom. To update later: uv tool upgrade staffroom. Install guide · What's new

What it does with your data

✓ Stays on this MacSettings, an index of your resources folder, a log of file paths.
✕ Never storedNames, candidate numbers or any row of marks: identifier columns are dropped on load.
⌕ Check itNo account, no server. Every file it keeps.
