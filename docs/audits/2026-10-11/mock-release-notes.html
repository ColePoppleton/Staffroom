Staffroom 0.8.0 Latest

11 Oct 2026 · Install or update: uv tool upgrade staffroom · Full changelog

For teachers

  • Forms only ask what matters. Worksheet shows Level only for truth tables; Quiz shows the taught log only in retrieval mode; choices read Easy / Medium / Hard.
  • Find files by tag. The Library has a Tags filter beside the type filter; both narrow the folder tree as well as search.
  • Better bug-hunt sheets. Bugs mixes crashes with programs that run but print the wrong thing, and the key shows an indentation slip with dots.
  • Settings are safer. A full disk can no longer leave your settings half-written.
